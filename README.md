# Login Form Website

A simple and responsive Login Form created using HTML and CSS.

## 🚀 Live Demo

[Visit Login Form](https://abhisheksadangi2.github.io/Login-Form/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Boxicons

## ✨ Features

- Username input
- Password input
- Remember Me option
- Forgot Password link
- Create Account link
- Login button
- Login with Facebook
- Login with Google
- Login with Twitter
- Responsive design
- Custom background image
